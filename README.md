# 🚀 How to Use This Repository

### Clone the repository

```bash
git clone https://github.com/bhargavlimbani/full-stack-training.git
```

### Open the project

```bash
cd MU
```

### Start learning module by module

* Begin with **HTML**
* Move to **CSS**
* Learn **JavaScript**
* Continue with **React**
* Learn **Node.js & Express**
* Finish with **MongoDB and full-stack projects**
